# Water Guardian — GitHub Pages version

This is a static HTML/CSS/JavaScript version of the Water Guardian water-pollution awareness prototype.

## Files
- `index.html` — page structure
- `style.css` — responsive design and styling
- `app.js` — navigation, pollution reporting demo, learning tips, points and profile

## Publish with GitHub Pages
1. Create or open a GitHub repository.
2. Upload **all three files** (`index.html`, `style.css`, `app.js`) into the repository's root folder (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then press **Save**.
6. Wait a minute or two and open the Pages URL shown there.

## Important
This version uses browser `localStorage`, so demo reports and points are saved on that device/browser only. It does not have a real backend, real user authentication, real map/location service, water-quality testing, or government reporting integration. The photo input is a visual prototype and does not upload files to a server.
